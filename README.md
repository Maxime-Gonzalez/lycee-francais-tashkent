# Lycée Français de Tachkent – site React

## Démarrage
```bash
npm install
npm run dev
```

## Logo
`public/images/logo-lycee-francais.png` est un **logo provisoire**. Remplacez-le par le logo officiel :
https://www.ecole-francaise-tachkent.com/wp-content/uploads/2022/09/Logo-lycee-francais.png

## Où modifier quoi
- Couleurs / typographies : `src/styles/tokens.css`
- Menu : `src/data/navigation.js` — URL : `src/routes.js`
- Contenu de l'accueil : `src/data/home.js`
- Header / Footer : `src/components/layout/`
